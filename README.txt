NSAYM BARKA LLTJART — Website starter
======================================

Files
- index.html: bilingual website content and layout
- styles.css: responsive design for desktop and mobile
- script.js: language switch and quotation form

Preview locally
1. Extract the ZIP.
2. Open index.html in a browser.
3. An internet connection is needed for the Google Fonts and remote demo photos.

Before publishing
1. Open script.js.
2. Replace the empty WHATSAPP_NUMBER with the company's WhatsApp number in international format, digits only.
   Oman example format: 9689XXXXXXX (replace with the real company number).
3. Replace illustrative photos with the company's actual project photos.
4. Confirm the official English spelling of the registered company name and add the real contact details.
5. Confirm the displayed location (Barka, Oman), test the Arabic/English toggle, and submit a test quotation to verify WhatsApp opens the correct chat.

Free hosting option
- GitHub Pages can host this static website for free. Create a GitHub account, create a public repository,
  upload index.html, styles.css, and script.js to the repository root, then enable Pages in repository Settings.
- A custom domain is optional and usually costs money; the free hosting address will be under github.io.

Important
- This is a front-end starter website. The form opens WhatsApp only after a company number is configured.
- It does not include a database, admin dashboard, online payments, or automatic email storage.
- Product photos currently are illustrative remote images, not verified photos of the company's work. Replace them with real project photos before or after launch.
